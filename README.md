# Card Pairs Game 🎴

A simple memory matching game where players flip cards to find matching pairs.  

## Tech Used
- HTML  
- CSS  
- JavaScript  

## How to Play
1. Click a card to reveal its symbol.  
2. Click a second card to find its match.  
3. Matching cards stay revealed; non-matching cards flip back.  
4. Match all pairs to win!  

have fun!
